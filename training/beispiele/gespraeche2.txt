=== gespraech code iterieren
@nutzer
Schreib mir eine Python-Funktion, die prüft, ob ein Wort ein Palindrom ist.
@max
```python
def ist_palindrom(wort):
    return wort == wort[::-1]
```

`wort[::-1]` dreht die Zeichenkette um. „anna“ ergibt `True`, „otto“ auch.
@nutzer
Bei "Anna" kommt False raus.
@max
Weil Groß- und Kleinschreibung zählt – „A“ ist nicht „a“. So ist es egal:

```python
def ist_palindrom(wort):
    wort = wort.lower()
    return wort == wort[::-1]
```
@nutzer
Und ganze Sätze, wie "Eine güldne, gute Tugend: Lüge nie!"?
@max
Dann müssen auch Leerzeichen und Satzzeichen raus:

```python
def ist_palindrom(text):
    buchstaben = [z.lower() for z in text if z.isalnum()]
    return buchstaben == buchstaben[::-1]
```

Damit zählen nur noch die Buchstaben, und dein Satz ergibt `True`. Umlaute wie das „ü“ sind kein Problem – `isalnum()` kennt sie.

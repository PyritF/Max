=== zwischenablage screenshot fehler
@nutzer
Ich hab einen Screenshot gemacht – was ist das für ein Fehler?
@max
```werkzeug
zwischenablage: Ich hab einen Screenshot gemacht – was ist das für ein Fehler?
```
@ergebnis
Bild aus der Zwischenablage:
Ein Windows-Dialogfenster mit dem Titel „Microsoft Visual C++ Runtime Library“. Text: „Runtime Error! Program: C:\Program Files\Spiel\game.exe. This application has requested the Runtime to terminate it in an unusual way.“ Darunter ein Button „OK“.
@max
Das ist ein **Absturz der Visual-C++-Laufzeit**: Das Spiel unter `C:\Program Files\Spiel\game.exe` hat sich mit einem Laufzeitfehler beendet. Die Meldung selbst ist leider sehr allgemein.

Was meistens hilft:

1. Die **Microsoft Visual C++ Redistributables** neu installieren (x86 und x64, von der Microsoft-Seite).
2. Die Spieldateien prüfen lassen – bei Steam über *Eigenschaften → Installierte Dateien → Dateien überprüfen*.
3. Grafiktreiber aktualisieren.

Tritt der Fehler immer an derselben Stelle im Spiel auf, spricht das eher für eine beschädigte Spieldatei als für dein System.

=== zwischenablage nicht von selbst
@nutzer

@max
Klar. Am sichersten ist eine **lange Passphrase** aus vier, fünf zufälligen Wörtern, etwa *Kaktus-Dampfer-Wolle-Nordlicht-17*. Die ist leicht zu merken und trotzdem schwer zu knacken.

=== zwischenablage code
@nutzer
Ich hab Code in der Zwischenablage, warum geht der nicht?
@max
```werkzeug
zwischenablage: Ich hab Code in der Zwischenablage, warum geht der nicht?
```
@ergebnis
Text in der Zwischenablage:
for i in range(10)
    print(i * 2)
@max
Nach der `for`-Zeile fehlt der **Doppelpunkt**:

```python
for i in range(10):
    print(i * 2)
```

Python verlangt ihn am Ende von `for`, `if`, `while` und `def`. Die Fehlermeldung dazu heißt meist *SyntaxError: expected ':'*.

namespace Demo;

public static class Rechner
{
    public static decimal Brutto(decimal netto, decimal steuersatz = 0.19m) =>
        Math.Round(netto * (1 + steuersatz), 2);

    public static decimal Netto(decimal brutto, decimal steuersatz = 0.19m) =>
        Math.Round(brutto / (1 + steuersatz), 2);
}
@max
`Rechner.cs` ist eine kleine Hilfsklasse für die **Mehrwertsteuer**:

- `Brutto(netto)` rechnet aus einem Nettobetrag den Bruttobetrag – standardmäßig mit 19 %.
- `Netto(brutto)` macht das Gegenteil.

Beide runden auf zwei Nachkommastellen und rechnen mit `decimal`, was bei Geldbeträgen genau richtig ist. Den Steuersatz kann man für 7 % einfach mitgeben: `Rechner.Brutto(100m, 0.07m)`.

=== kein werkzeug erklaerung
@nutzer
Warum ist der Himmel blau?
@max
Weil Sonnenlicht an den Molekülen der Luft gestreut wird – und zwar kurzwelliges blaues Licht viel stärker als rotes. Dieses gestreute Blau kommt aus allen Richtungen bei uns an, also leuchtet der ganze Himmel blau. Bei Sonnenuntergang ist der Weg durch die Luft so lang, dass das Blau unterwegs weggestreut wird und vor allem Rot und Orange übrig bleiben.
